הפרויקטים שלי

הפרויקטים נשמרים אוטומטית בדפדפן הזה בלבד. מומלץ לייצא גיבוי מדי פעם.

    ייצוא MIDI

    ערוצים לייצוא

    קובץ MIDI תקני (Type 1, 480 PPQ): טמפו, משקל, סולם, ערוץ נפרד לכל כלי עם שם ותוכנית General MIDI. בקיובייס: File › Import › MIDI File.

    איך עובדים עם ChordFlow

    1. כותבים אקורדים בתיבה העליונה, או בוחרים "התחלה מהירה" או אקורדים מהסולם.
    2. בוחרים סגנון לפסנתר ולבס: תבנית נגינה, פריסת אקורד (voicing), אוקטבה וצליל.
    3. מאזינים עם רווח, מתקנים על ציר הזמן (גרירה, אורך, היפוכים).
    4. מייצאים MIDI ופותחים בקיובייס: כל כלי בערוץ משלו, עם טמפו וסמני אקורדים.
