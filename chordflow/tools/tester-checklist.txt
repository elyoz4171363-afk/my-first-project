ChordFlow v2 · בית ליוצרים - הוראות בדיקה
=========================================

מה יש כאן
---------
1. ChordFlow-v2.html: הכלי עצמו. פותחים בלחיצה כפולה בדפדפן (Chrome, Edge, Firefox או Safari). לא צריך התקנה.
   התיקייה samples (הקלטות הכלים) צריכה להישאר ליד הקובץ. מחלצים את כל ה-zip לתיקייה אחת.
2. ChordFlow-דוגמה-תזמורתית.mid: קובץ MIDI לדוגמה שיצא מהכלי (פסנתר, כלי קשת, צ׳לו, קרנות יער, קונטרבס).

חשוב לדעת
---------
- הצליל בדפדפן מבוסס על הקלטות של כלים אמיתיים, אבל הוא רק תצוגה מקדימה. הסאונד הסופי מגיע מהספריות בקיובייס.
- בלחיצה הראשונה על נגן הצלילים נטענים, וזה לוקח שנייה או שתיים.
- הפרויקטים נשמרים בדפדפן שבו פתחתם את הקובץ.
- הכלי נפתח בתצוגה נקייה. כפתור "עריכה" למעלה פותח את כל הכלים והמאפיינים (גם לחיצה על כלי פותחת אותו).
- "עוד" למעלה: פרויקטים, חדש, מעבר בין מצב שחור לשמנת, וקרדיטים.
- בטלפון יש מסך קריאה והשמעה בלבד. העריכה במחשב.
- "בדיקה בקיובייס - 8 שורות.txt": הבדיקה הכי חשובה, כעשר דקות.

בדיקה 1: עבודה בסיסית (5 דקות)
--------------------------------
[ ] הכלי נפתח בלי הודעות שגיאה
[ ] כותבים רצף אקורדים, למשל:  Dm7 | G7 | Cmaj7 | A7b9  ולוחצים "יצירת עיבוד"
[ ] כותבים אקורד שגוי (למשל H7) ומוודאים שמופיעה הודעה ברורה
[ ] נגן (גם מקש רווח): שומעים את העיבוד, וסמן הנגינה זז
[ ] לולאה ועצירה עובדות
[ ] מטרונום: מדליקים, משנים עוצמה, ובוחרים משקל 6/8 או 7/8 (עם חלוקה 2+2+3 / 3+2+2). ההקשות צריכות להיות לפי המשקל
[ ] גוררים אקורד בציר הזמן, ומשנים אורך בגרירת הקצה הימני
[ ] Ctrl+Z מבטל את השינוי האחרון

בדיקה 2: כלים ודינמיקה
-----------------------
[ ] "בחירת הרכב" → "קולנועי" או "רביעיית כלי קשת"
[ ] "הוספת כלי" → כלי נשיפה או כלי קשת נוסף
[ ] לוחצים על כלי, ובלשונית "דינמיקה" משנים: רמה (pp עד ff), "כמה מרגש", צורת תנועה
[ ] הגרף בתחתית לשונית הדינמיקה משתנה בהתאם
[ ] "עקומת השיר": קליק מוסיף נקודה, גרירה מזיזה, קליק ימני / Delete / לחיצה ארוכה מוחקים, ↺ מאפס. אסור שיצטברו נקודות כפולות
[ ] בלשונית "דינמיקה": "האזנה לכלי לבד" ואז משנים רמה, צורה ו"כמה מרגש". השינוי נשמע מיד
[ ] כפתור "pp → ff" משמיע את אותו אקורד חלש ואחר כך חזק. ההבדל צריך להיות ברור
[ ] למעלה ליד השם כתוב "צלילים מוקלטים ✓" (אם כתוב "צלילים מסונתזים", חסרה תיקיית samples)

בדיקה 2ב: הכלים החדשים
-----------------------
[ ] מבנה שיר: כותבים בשורת האקורדים  [בית] Am | F | C | G | [פזמון] F | G | Em | Am  ← "יצירת עיבוד"
    לוחצים על "פזמון" בפס החלקים ובוחרים אילו כלים מנגנים, תבנית ועוצמה. שומעים שהפזמון נפתח
[ ] עריכה: Ctrl+קליק על כמה אקורדים · Ctrl+C ואז Ctrl+V · קליק ימני על האקורדים לתפריט · S פיצול · J איחוד
[ ] מלודיה: "הוספת כלי" → "קו מלודיה" → מקלידים  E D C D | E E E -  → "עדכון המלודיה". הליווי לא עולה מעליה
[ ] מלודיה מקובץ: "ייבוא מקובץ MIDI…"
[ ] ייצוא → "שמע (WAV)": כל ההרכב, כלי לבד, ו"הכל חוץ מכלי אחד" (ליווי לתלמיד)
[ ] ייצוא → "דף אקורדים": הדפסה, גם עבור כלי ב-Bb

בדיקה 3: ייצוא לקיובייס (הכי חשוב)
----------------------------------
[ ] "ייצוא" → לשונית MIDI → הורדת קובץ
[ ] בקיובייס: File › Import › MIDI File
[ ] כל כלי נפתח בטרק נפרד עם השם שלו
[ ] הטמפו והמשקל נכונים, ושמות האקורדים מופיעים כסמנים (Markers)
[ ] מחברים ספריית קשת או נשיפה (Spitfire, BBC, CSS, Berlin או אחרת) ובודקים:
    - CC1 (Modulation) מזיז את הדינמיקה כמו שצריך
    - CC11 (Expression) נשמע טבעי, בלי קפיצות
    - ה-Velocity הגיוני (לא חזק מדי, ולא חלש מדי)
[ ] Keyswitches: בייצוא פותחים "ארטיקולציות", מדליקים, ומתאימים את התווים למפה של הספרייה שלכם.
    בודקים שהספרייה עוברת לבד בין לגאטו / ספיקטו / טרמולו
[ ] החלקים (Verse / Chorus) מופיעים כסמנים בקיובייס
[ ] אותה בדיקה עם הקובץ לדוגמה המצורף
