ChordFlow v2 · בדיקה בקיובייס · 8 שורות, כעשר דקות
====================================================
לפני: בכלי בוחרים "בלדה תזמורתית", לוחצים "עריכה", ובחלון MIDI משאירים פדל דלוק וחפיפת לגאטו 40.

[ ] 1. ייצוא › MIDI › הורדה. בקיובייס: File › Import › MIDI File. כל כלי נפתח בטרק משלו, עם השם שלו.
[ ] 2. הטמפו והמשקל בסרגל נכונים, ושמות האקורדים והחלקים (Verse / Chorus) מופיעים בטרק הסמנים.
[ ] 3. פסנתר ב-Key Editor, שורת בקר CC64: הפדל עולה ויורד בכל החלפת אקורד, והצליל לא נמרח.
[ ] 4. טרק כלי קשת, שורות CC1 ו-CC11: עקומות חלקות בלי קפיצות, והדינמיקה נשמעת חיה עם ספרייה תזמורתית.
[ ] 5. מעברי לגאטו: הספרייה מחברת בין התווים (חפיפה של 40ms), ולא מתחילה כל תו מחדש.
[ ] 6. בייצוא מדליקים "ארטיקולציות", מתאימים את התווים לספרייה, ומורידים גם MIDI וגם Expression Map.
       בקיובייס: Inspector › Expression Map › Setup › Import. שמות הארטיקולציות מופיעים, והספרייה עוברת לבד בין לגאטו, ספיקטו וטרמולו.
[ ] 7. MIDI חי: loopMIDI ב-Windows או IAC ב-Mac. בכלי: MIDI › יציאה › "לשלוח את הנגינה". בקיובייס הפורט הוא הכניסה של הטרקים ומקליטים.
       התווים מגיעים בזמן, כל כלי בערוץ שלו, ועצירה לא משאירה תווים תקועים.
[ ] 8. קלידים לכלי: MIDI › כניסה. מנגנים ושומעים מיד, הפדל עובד, והמספר "מהקלידים לצליל" מופיע.

מה לשלוח בחזרה: מספר השורה שנכשלה, גרסת קיובייס, שם הספרייה, וצילום מסך.
