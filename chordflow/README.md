# ChordFlow · בית ליוצרים

כלי דפדפן עצמאי שהופך רצף אקורדים לעיבוד: קלידים, בס, כלי קשת, נשיפה ממתכת, נשיפה מעץ ופדים. לכל כלי קובעים דינמיקה ואקספרשן, ומייצאים קובץ MIDI רב-ערוצי עם Velocity, ‏CC1 ו-CC11, מוכן לספריות תזמורתיות בקיובייס.

אין צורך בשרת, אין חשבון ואין תלות בשירות בתשלום. כל הצליל נוצר בדפדפן עם Web Audio.

## הפעלה

- פותחים את `index.html` בדפדפן, ישירות מהקובץ (גם `file://` עובד).
- או מעלים את התיקייה `chordflow/` כמו שהיא לכל אחסון סטטי: GitHub Pages, Netlify, או תיקייה באתר הקיים.
- הגופנים נטענים מ-Google Fonts. בלי רשת הכלי ממשיך לעבוד עם גופן מערכת.

### פתיחה בקיובייס

`File › Import › MIDI File`. כל כלי נפתח כטרק נפרד עם השם שלו, הטמפו והמשקל נקלטים, ושמות האקורדים מופיעים כ-Markers.

## מבנה הקוד

```
chordflow/
  index.html          ממשק (RTL)
  css/chordflow.css   עיצוב המותג
  js/theory.js        שמות תווים, סולמות, פענוח אקורדים, ספרות רומיות
  js/registry.js      רישום כלים, פריסות ומסלולי מנוי (Plans)
  js/voicing.js       מנוע voicings והיפוכים
  js/patterns.js      תבניות נגינה (פסנתר / בס)
  js/dynamics.js      רמות, צורות, עקומת השיר, Velocity ו-CC
  js/arranger.js      פרויקט → תווים ובקרים. אותה תוצאה משמשת לנגן ולייצוא
  js/midi.js          כתיבת קובץ MIDI תקני
  js/project.js       מודל פרויקט, פענוח טקסט הרצף, אחסון וגיבוי
  js/audio.js         מנוע Web Audio: כלים מסונתזים, מתזמן, לולאה
  js/app.js           ממשק ועריכה
  tests/run-tests.js  בדיקות מנוע ו-MIDI (node chordflow/tests/run-tests.js)
```

הסקריפטים רגילים, בלי שלב build, ולכן הכלי נפתח גם מ-`file://`.

## הרחבה ותכונות בתשלום

- **תבנית נגינה חדשה:** `CF.Patterns.register('piano' | 'bass', { id, name, desc, tier, generate(c) })`. התבנית מופיעה אוטומטית בממשק, בנגן ובייצוא.
- **כלי חדש:** `CF.Instruments.register({ id, role, name, program, tier })` ומימוש צליל ב-`VOICES` שב-`audio.js`.
- **מסלול בתשלום:** כל פריט ברישום מקבל `tier`. רושמים חבילה עם `tier: 'pro'`, ואחרי אימות רישיון קוראים ל-`CF.Plans.unlock('pro')`. הממשק מציג רק את מה שהמסלול הנוכחי כולל.
- **ערוץ נוסף (תופים, פד):** מוסיפים role ב-`defaultTracks()` שב-`project.js`, ותבניות ל-role הזה. הארנג׳ר והייצוא כבר עובדים על רשימת ערוצים.

## בדיקות

```bash
node chordflow/tests/run-tests.js
```

הבדיקות מכסות את פענוח האקורדים, הסולמות, טקסט הרצף, ה-voicings, כל צירופי התבניות בכל המשקלים, ואת קובצי ה-MIDI עצמם. קובצי ה-MIDI נקראים בקורא עצמאי שבודק מבנה, איזון Note On/Off, הפרדת ערוצים, טמפו, סולם וסמנים.
